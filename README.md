# FloodGuard AI

AI-Powered Flood Prediction and Alert System

## Overview
FloodGuard AI is a full-stack intelligent flood prediction system that monitors 24 flood-prone cities across 8 Indian states using real-time weather data, dual ML models (Random Forest + LSTM), and automated email/SMS alerts.

## Tech Stack
- **Frontend**: React.js + Recharts + React Leaflet
- **Backend**: Node.js + Express + JWT Auth
- **ML Service**: Python + FastAPI + TensorFlow/Keras
- **Database**: Supabase (PostgreSQL)
- **Alerts**: Nodemailer (Email) + Fast2SMS (SMS)
- **Data**: Open-Meteo API (free, real-time)

## Project Structure
- data-collector/ - Hourly weather data collection
- ml-service/     - ML model training and FastAPI server
- backend/        - Node.js REST API and alert system
- frontend/       - React.js web dashboard
